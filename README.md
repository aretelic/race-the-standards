# Race the Standards

**Prototype**: an early, mobile-first idea for Leander Swimming Club (Tooting, London), not a finished product.

A swimmer enters their age, gender, pool length, stroke and personal best (PB). An animated race then shows how they compare with the county qualifying and consideration times.

- **County times** come from the Surrey County Age Group Championships 2027 (v1).
- **Regional and national lanes are placeholders.** They're estimated as 95% and 90% of the county qualifying time until real standards are added.

It's a single file (`index.html`) with no dependencies. Open it in any browser.
